# Vehicle Mileage Audit

## MG3012 Assignment 3



Vehicle Mileage Audit records mileage inspections for a fictional car. Each inspection stores the dashboard reading and two simulated internal module readings. The contract flags disagreements and readings below the last accepted mileage. An authorized reviewer can correct the accepted mileage and record a reason while preserving the original readings.



**This project reuses the Assignment 2 smart contract and deploys it to a local Ganache blockchain using Truffle.**



##### Setup



Install Node.js with npm and Python 3. Open a command window in the project folder and install the project dependencies.



```cmd

**npm install**

```



Start Ganache in that window and leave it running.



```cmd

**npx ganache --server.host 127.0.0.1 --server.port 8545 --chain.chainId 1337 --chain.networkId 1337**

```



Open a second command window in the project folder. Compile the contract, deploy it to Ganache, and start the frontend server.



```cmd

**npx truffle compile**

**npx truffle migrate --network development**

**py -m http.server 8001 --bind 127.0.0.1**

```



Open \[the local dashboard](http://127.0.0.1:8001/frontend/) in your browser. The dashboard reads the contract address from the file generated by Truffle. It uses Ganache’s first test account as the reviewer and its second test account as the reporter.



#### Test the demo



1\. On a fresh deployment, check that the accepted mileage is **95,000** km.

2\. Enter **50000** for Dashboard and **100000** for both modules. Click **Submit as reporter**. The page should show **Needs review** and keep the accepted mileage at **95,000 km**.

3\. Enter **100000** and the reason \*\*Both internal modules reported **100000 km**. Click **Resolve as reviewer**.

4\. Check that the page shows **100,000 km** · No open review\*\*. The inspection history should still show the original dashboard reading of **50,000 km** alongside the reviewer’s decision.
